ImmortalWrt 简介

ImmortalWrt 是基于 OpenWrt 的一个第三方分支，由国人开发者维护，主要面向中文用户优化。相比原版 OpenWrt，ImmortalWrt 提供了更丰富的本地化软件包、更友好的 LuCI 中文界面，以及对国内常用硬件（如迅驰、友善等）的更好支持。

选择 ImmortalWrt 的核心理由：

  • 本地化支持：预集成国内常用的上网认证、多拨、流控等插件
  • 硬件适配广：对 ARM/x86 等平台的兼容性更好，支持更多迅驰、友善等软路由设备
  • 开箱即用：默认启用中文 LuCI 界面，预置常用工具链，无需额外编译

固件选择

以 x86/64 平台 25.12.1 版本 为例，固件文件名由以下几部分组成，理解它们的含义才能选对固件：

文件系统类型

类型 说明
ext4 可读写的文件系统，支持保存数据和安装软件，推荐日常使用
squashfs 只读压缩文件系统，体积更小、启动更快，但修改需要 overlay，适合嵌入式 Flash 设备, 可一键恢复出厂设置

常见搭配方案（嵌入式 / Linux 发行版经典用法）

squashfs（只读系统本体） + ext4（可写数据分区）

  • 系统内核、程序、库放在 squashfs（压缩只读，省空间、防破坏）
  • 用户配置、日志、数据挂载独立 ext4 分区存放可写内容

镜像类型

类型 说明
combined 内核 + 根文件系统 + U-Boot 打包在一起，整盘写入即可使用，推荐首选
rootfs 仅根文件系统部分，需单独配合内核使用，适合已有引导环境的场景
kernel 仅内核文件，单独使用需自行挂载 rootfs
image.iso 安装光盘镜像，用于物理机光驱引导安装

启动模式

类型 说明
efi UEFI 启动（如 *-efi.img.gz），适用于现代主板和虚拟机
无后缀 Legacy 传统 BIOS 启动

虚拟磁盘格式

类型 适用场景
img.gz 通用裸磁盘镜像，可直接 dd 写盘或写入磁盘，物理安装首选
qcow2 QEMU/KVM 虚拟机格式，Proxmox、ESXi（需转换）等虚拟化平台使用
vdi VirtualBox 虚拟硬盘格式
vhdx Hyper-V / WSL2 虚拟硬盘格式
vmdk VMware 虚拟硬盘格式

推荐选择

  • 物理机 / 软路由刷机：generic-ext4-combined.img.gz（整盘写入，dd 或 Rufus 即可）
  • Proxmox / KVM 虚拟化：generic-ext4-combined-efi.qcow2.gz
  • VMware 虚拟化：generic-ext4-combined-efi.vmdk.gz
  • 首次安装测试：generic-image-efi.iso（光盘引导安装）

附 opkg 软件源镜像

腾讯云 https://mirrors.cloud.tencent.com/openwrt
华为云 https://mirrors.huaweicloud.com/repository/openwrt
