Windows 将复制粘贴改为 Alt+C / Alt+V 完整方案

Windows 系统原生无法直接全局替换 Ctrl+C/V，有两种稳定实现方法：AutoHotkey（推荐，自由度最高）、微软官方工具 PowerToys Keyboard Manager。

方案二：微软官方 PowerToys（无需第三方脚本，图形界面）

1. 安装 PowerToys

微软商店直接搜索安装，或 GitHub 下载。

2. 设置快捷键映射

  1. 打开 PowerToys → 左侧 Keyboard Manager，开启开关
  2. 点击 Remap a shortcut（重映射快捷键）
  3. 点 Add remapping，按下面填写两组规则：
    输入（你按的） 输出（系统执行） 生效范围
    Alt + C Ctrl + C All apps（全局）
    Alt + V Ctrl + V All apps（全局）
  4. 保存，弹窗提示冲突点「Continue anyway」即可。

优缺点对比

  • AutoHotkey：兼容性极强（游戏、软件、浏览器都不翻车）、可加更多Mac风格快捷键、能一键临时关闭；
  • PowerToys：官方工具，不用写代码，但部分软件（微信、游戏）会拦截Alt快捷键，偶尔失效。

重要注意事项

  1. Alt 本身有系统原生功能：Alt+C、Alt+V 原本是窗口菜单快捷键，开启映射后会覆盖原有Alt菜单快捷键，无法同时使用；
  2. 两种方案都不会禁用 Ctrl+C/V，两套快捷键并行可用；
  3. 游戏/全屏软件失效：优先用 AutoHotkey，右键脚本「以管理员身份运行」即可解决。
