Hexo从入门到入土

一、部署平台选择

Hexo 是纯静态站点生成器，生成的 public/ 目录可以部署到任何支持静态文件托管的平台。选择平台时主要考虑：访问速度、费用、备案要求、自定义域名支持、自动化部署能力。

1.1 GitHub Pages

最经典的 Hexo 部署平台，适合个人开发者和技术博客用户，生态成熟但国内访问速度一般。

对比与推荐：作为入门首选，完全免费且无需备案，但如果博客目标读者主要在国内，建议配合 CDN 加速或作为镜像源站使用。

  • 免费托管静态网站
  • 支持自定义域名
  • 配合 hexo-deployer-git 插件一键部署
  • 支持 HTTPS（Let’s Encrypt）
  • 访问速度在中国大陆较慢

1.2 Gitee Pages

GitHub Pages 的国内替代品，国内访问速度明显优于 GitHub，但限制较多。

对比与推荐：如果不打算备案且读者主要在国内，可作为主部署平台使用；但需注意免费版有流量限制，且自定义域名需要审核。与 GitHub Pages 双部署也是常见方案。

  • 国内访问速度快
  • 免费版有流量限制
  • 支持自定义域名（需审核）
  • 配合 hexo-deployer-git 插件部署
  • 需要实名验证

1.3 Vercel

全球领先的 Serverless 部署平台，以 Git 推送即部署为核心优势，Hexo 官方文档推荐的部署平台之一。

对比与推荐：推荐追求部署体验和全球访问速度的用户使用。相比 Netlify，Vercel 在国内访问速度略好，且对前端框架的原生支持更优。免费版对个人博客绰绰有余。

  • 全球 CDN 加速
  • 支持 Git 自动部署
  • 支持 Serverless Functions
  • 免费版额度充足
  • 支持自定义域名和 HTTPS

1.4 Netlify

老牌 Jamstack 平台，功能丰富，生态成熟，与 Vercel 齐名的两大静态站点托管平台之一。

对比与推荐：如果需要表单收集、身份认证（Identity）等内置功能，Netlify 比 Vercel 更合适。两者免费额度相近，均可通过 Push 到 Git 自动触发部署。

  • 全球 CDN 加速
  • 支持 Git 自动部署
  • 支持表单、Identity 等功能
  • 免费版额度充足
  • 支持自定义域名和 HTTPS

1.5 Cloudflare Pages

依托 Cloudflare 全球 CDN 网络，速度极快，且与 Cloudflare 其他产品（DNS、CDN、WAF）无缝集成。

对比与推荐：如果你已经在用 Cloudflare DNS，那么 Pages 是最佳选择，无需额外配置即可享受其全部网络加速和安全防护。免费版构建额度为 500 次/月，对个人博客完全够用。

  • 全球 CDN 加速（Cloudflare 网络）
  • 支持 Git 自动部署
  • 免费版额度充足
  • 可配合 Cloudflare DNS 使用
  • 支持 Functions

1.6 阿里云 OSS / 腾讯云 COS

国内云厂商的对象存储服务，本质是”付费版 GitHub Pages”，配合 CDN 使用可达到极致的国内访问速度。

对比与推荐：适合对访问速度要求极高、且已完成域名备案的用户。费用低廉（通常每月几元到几十元），但备案是硬门槛。阿里云与腾讯云体验相近，可根据已有云服务选择同厂商。

  • 对象存储托管静态网站
  • 国内访问速度快
  • 按流量计费
  • 支持 CDN 加速
  • 需备案（绑定自定义域名时）

1.7 自己的服务器/VPS

自由度最高的方案，用一台虚拟服务器通过 Nginx/Apache 托管 public/ 目录。

对比与推荐：仅推荐有运维经验、且需要额外功能（如部署 API、数据库、私有服务）的用户。虽然可以装宝塔面板降低门槛，但服务器安全、证书更新、备份都需要自己维护，对纯博客场景来说性价比不高。

  • 完全可控
  • 使用 Nginx / Apache 托管
  • 支持更多扩展功能
  • 需要自行维护服务器
  • 需备案（国内服务器）

二、常用插件及功能

Hexo 的核心优势在于其丰富的插件生态，通过 npm install 即可按需安装。推荐只装必需插件，过多插件会拖慢 hexo generate 构建速度。

2.1 评论系统

静态站点本身没有后端，评论系统是博客互动的核心。选择时主要考虑：国内访问速度、是否需要登录、数据归属。

推荐方案：国内用户首选 Giscus（基于 GitHub Discussions，无需额外后端）或 Waline（自建后端，功能最全）。Gitalk 因基于 Issue 会污染仓库 Issue 列表，已不推荐。

  • Disqus：国际主流评论系统，国内访问不稳定
  • Gitalk：基于 GitHub Issue 的评论系统，需 GitHub 账号
  • Giscus：基于 GitHub Discussions 的评论系统
  • Valine：基于 LeanCloud 的无后端评论系统
  • Waline：Valine 的衍生版本，支持更多功能
  • ** utterances**：基于 GitHub Issue 的轻量评论系统
  • 来必力（Livere）：韩国的评论系统，有中文版
  • 畅言：搜狐旗下评论系统，国内访问快，需备案

2.2 搜索功能

静态站点的搜索有两种思路：构建时生成索引文件前端本地搜索，或使用第三方搜索服务（如 Algolia）。

推荐方案：文章少于 500 篇时，本地搜索 + hexo-generator-searchdb 足够用，体验好且无依赖；博文量巨大时再考虑 Algolia。

  • hexo-generator-search：生成搜索索引（XML/JSON）
  • hexo-generator-searchdb：生成搜索数据库
  • Algolia：第三方搜索服务，速度快
  • 本地搜索：配合主题内置的搜索功能

2.3 文章增强

这一类插件扩展文章本身的元信息和展示效果，其中大部分属于”装了就不用管”的基础插件。

必装推荐：hexo-abbrlink（URL 永久化，防止文章修改后链接失效）、hexo-generator-sitemap（SEO 必需）、hexo-generator-feed（RSS 订阅）。其余按需安装。

  • hexo-abbrlink：生成文章唯一 ID（短链接）
  • hexo-generator-sitemap：生成站点地图
  • hexo-generator-feed：生成 RSS 订阅
  • hexo-asset-image：文章资源图片管理
  • hexo-wordcount：字数统计
  • hexo-reading-time：阅读时长估算
  • hexo-toc：生成目录
  • hexo-footnotes：脚注支持

2.4 代码高亮

Hexo 内置了 highlight.js 高亮，此外 Prism.js 也是流行方案。如今多数 Fluid、Butterfly 等主题都已内置高亮，无需单独装插件。

推荐方案：优先使用主题自带的高亮方案，配置最简单。如需自定义风格，再考虑 Prism 插件。

  • hexo-prism-plugin：Prism.js 代码高亮
  • hexo-highlight：内置代码高亮
  • 主题自带高亮：多数主题自带高亮方案

2.5 数学公式

对理工类博客、算法笔记必需。主要有两大引擎：MathJax（功能完整、渲染质量高但慢）和 KaTeX（速度快但部分语法不支持）。

推荐方案：绝大多数情况下优先选择 KaTeX（hexo-katex），在构建时预渲染公式，页面加载速度远快于 MathJax。

  • hexo-math：MathJax 支持
  • hexo-katex：KaTeX 支持（更快）
  • hexo-filter-mathjax：MathJax 过滤器

2.6 图片处理

图片是博客加载速度的大头，懒加载和响应式图片对移动端体验和 Core Web Vitals 分数都至关重要。

推荐方案：hexo-lazyload-image 几乎必装（也可让主题内置处理）。响应式图片插件按需选用，现代 CDN（如 Cloudflare）一般已自动处理。

  • hexo-lazyload-image：图片懒加载
  • hexo-image-sizes：自动生成响应式图片
  • hexo-filter-responsive-images：响应式图片

2.7 SEO 优化

搜索引擎流量是博客的重要访客来源。除了 sitemap 和分类归档生成器，主动推送 URL 给百度等搜索引擎可以大幅提升收录速度。

推荐方案：sitemap、archive/category/tag 四个 generator 属于标配必装。国内博客再加一个搜索引擎主动推送插件。

  • hexo-generator-seo-friendly-sitemap：SEO 友好的站点地图
  • hexo-baidu-url-submit：百度主动推送
  • hexo-submit-urls-to-search-engine：主动推送到搜索引擎
  • hexo-seo-autopush：SEO 自动推送
  • hexo-generator-archive：归档页生成
  • hexo-generator-category：分类页生成
  • hexo-generator-tag：标签页生成

2.8 部署相关

部署插件将 hexo deploy 命令与对应平台对接，一推即发。常用的 Git 部署插件几乎人人都装。

必装：hexo-deployer-git（除了 Vercel/Netlify 这种 Git 自动构建的平台外都需要）。其余根据实际部署平台选装。

  • hexo-deployer-git：Git 部署（GitHub/Gitee 等）
  • hexo-deployer-rsync：Rsync 部署
  • hexo-deployer-sftp：SFTP 部署
  • hexo-deployer-aliyun-oss：阿里云 OSS 部署
  • hexo-deployer-cos：腾讯云 COS 部署

2.9 安全与防护

静态站点的安全风险相对较少，主要是外链权重流失和 SEO 方面的问题。

推荐：选装一个 nofollow 插件即可，自动给所有出站链接加上 rel="nofollow noopener noreferrer"，既防权重流失也防安全风险。

  • hexo-nofollow：外链自动添加 nofollow
  • hexo-filter-nofollow：外链 nofollow 过滤器

2.10 其他实用插件

各种杂项实用工具。其中迁移插件只在从别的博客系统搬到 Hexo 时用一次。

推荐：hexo-all-minifier（压缩资源、加速访问）和 hexo-browsersync（开发时热刷新）是提升体验的加分项。hexo-admin 适合不熟悉命令行的用户，但安全性需注意。

  • hexo-admin：后台管理界面
  • hexo-draft：草稿功能
  • hexo-migrator-wordpress：从 WordPress 迁移
  • hexo-migrator-rss：从 RSS 迁移
  • hexo-all-minifier：压缩 HTML/CSS/JS
  • hexo-browsersync：浏览器实时刷新
  • hexo-server：本地预览服务器

三、中国大陆地区相关操作

Hexo 部署在海外平台虽然省事免备案，但国内访问慢、搜索引擎收录差是硬伤。本章专门针对国内用户整理了从备案、加速、合规到 SEO 的全套实操注意事项。

3.1 ICP 备案

ICP 备案是国内合法建站的前提，本质是向工信部提交网站信息，由接入服务商（云厂商）代为审核。是否需要备案的判断标准只有一个：网站内容是否托管在中国大陆的服务器/CDN 上。

建议：如果打算长期运营博客并面向国内读者，尽早备案是最佳选择。备案本身免费，但需要 1-3 周审核时间，期间网站暂时无法通过自定义域名访问国内节点。

  • 使用国内服务器/云服务必须备案
  • 使用国内 CDN 绑定自定义域名需备案
  • 阿里云 OSS / 腾讯云 COS 绑定自定义域名需备案
  • 备案需提供身份证、域名证书等材料
  • 备案周期通常为 7-20 个工作日
  • 个人备案与企业备案流程不同

3.2 GitHub Pages 加速方案

直接用 GitHub Pages 国内访问经常超时或加载缓慢，常见做法是用 CDN 做一层代理加速，或者同时部署国内镜像站点。

推荐方案：Cloudflare CDN 是免费方案首选，国内大部分地区访问速度有明显改善；如果效果还不理想，可以 jsDelivr 托管静态资源 + GitHub Pages 主站混合使用。

  • Cloudflare CDN：免费 CDN，全球加速
  • jsDelivr：免费 CDN，加速静态资源
  • 七牛云 / 又拍云：国内 CDN，需备案
  • Gitee Pages 镜像：国内镜像站点
  • Vercel / Netlify：海外平台但国内访问尚可
  • 静态资源 CDN 托管：图片、JS、CSS 放 CDN

3.3 国内访问优化

除了部署和 CDN，前端层面的优化也非常关键：减少甚至去掉海外资源依赖（Google Fonts、Gravatar 是重灾区），启用压缩和现代图片格式都能显著降低首屏耗时。

重点关注：Gravatar 头像如果不替换为国内镜像（Cravatar），评论区头像经常加载不出来，是最常被忽略的细节。

  • 使用国内 CDN 加速静态资源
  • 图片使用国内图床（七牛云、又拍云、SM.MS 国内版）
  • 减少海外资源依赖（Google Fonts、Gravatar 等）
  • 替换为国内镜像：
    • Google Fonts → 字体天下 / 百度静态资源
    • Gravatar → Cravatar / 七牛镜像
    • Disqus → 国内评论系统
  • 启用 Gzip / Brotli 压缩
  • 图片懒加载和 WebP 格式

3.4 合规要求

国内建博客除了 ICP 备案外，还有一些展示和合规要求。不遵守最严重会导致网站被 DNS 阻断或接入商封站。

最容易遗漏：备案号必须可点击跳转到工信部备案查询页（https://beian.miit.gov.cn/），只写文字不链接属于不合规。

  • 网站备案号：备案后需在页脚展示备案号
  • 公安备案：部分地区要求公安备案
  • 隐私政策：收集用户信息需提供隐私政策
  • 版权声明：原创内容声明

3.5 域名相关

域名在哪里注册不影响备案和解析，但域名后缀和实名认证要求不同。注意部分冷门后缀无法备案。

推荐：追求性价比选 Namecheap 或 Cloudflare（免费域名隐私保护）；需要国内售后和方便备案选 阿里云/腾讯云。国内域名必须实名认证后才能解析，这点要注意。

  • 国内域名注册：阿里云、腾讯云、华为云
  • 国外域名注册：Namecheap、GoDaddy、Cloudflare
  • 域名解析：国内推荐 DNSPod、阿里云解析；国外推荐 Cloudflare
  • 域名实名认证：国内域名必须实名认证

3.6 国内图床选择

图床选得不好会导致图片加载慢、甚至被封外链。判断图床好坏的标准：是否支持 HTTPS、是否有防盗链、是否可绑定自定义域名、免费额度多少。

推荐方案：个人博客首选 七牛云免费额度 10GB 足够用；如果图量大走 腾讯云 COS 或阿里云 OSS 按量付费，每月几元成本。不推荐使用 SM.MS 免费版放重要图片，删图政策较随意。

  • 七牛云（免费额度 10GB/月）
  • 又拍云（需要申请联盟）
  • 腾讯云 COS（按量付费）
  • 阿里云 OSS（按量付费）
  • SM.MS（有免费版）
  • 自建图床（需要服务器）

3.7 搜索引擎优化（国内）

国内搜索引擎市场以百度为主（约占 60%+），其次是微信搜一搜、360、搜狗等。和 Google 不同，百度对纯静态新站收录慢，需要主动提交 URL 才能加快收录。

核心建议：务必开通并验证百度搜索资源平台，配合 hexo 主动推送插件实时推送新文章 URL，否则一个新站可能等 3-6 个月才被收录。神马搜索专门针对 UC 浏览器移动端，搜狗对应微信公众号生态，也可一并提交。

  • 百度搜索资源平台提交
  • 百度主动推送（实时推送）
  • 百度自动推送（JS 代码）
  • 360 搜索站长平台
  • 搜狗站长平台
  • 神马搜索站长平台
  • 生成百度网站地图（sitemap）
