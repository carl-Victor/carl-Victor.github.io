Hexo从入门到入土

一、部署平台选择

1.1 GitHub Pages

  • 免费托管静态网站
  • 支持自定义域名
  • 配合 hexo-deployer-git 插件一键部署
  • 支持 HTTPS（Let’s Encrypt）
  • 访问速度在中国大陆较慢

1.2 Gitee Pages

  • 国内访问速度快
  • 免费版有流量限制
  • 支持自定义域名（需审核）
  • 配合 hexo-deployer-git 插件部署
  • 需要实名验证

1.3 Vercel

  • 全球 CDN 加速
  • 支持 Git 自动部署
  • 支持 Serverless Functions
  • 免费版额度充足
  • 支持自定义域名和 HTTPS

1.4 Netlify

  • 全球 CDN 加速
  • 支持 Git 自动部署
  • 支持表单、Identity 等功能
  • 免费版额度充足
  • 支持自定义域名和 HTTPS

1.5 Cloudflare Pages

  • 全球 CDN 加速（Cloudflare 网络）
  • 支持 Git 自动部署
  • 免费版额度充足
  • 可配合 Cloudflare DNS 使用
  • 支持 Functions

1.6 阿里云 OSS / 腾讯云 COS

  • 对象存储托管静态网站
  • 国内访问速度快
  • 按流量计费
  • 支持 CDN 加速
  • 需备案（绑定自定义域名时）

1.7 自己的服务器/VPS

  • 完全可控
  • 使用 Nginx / Apache 托管
  • 支持更多扩展功能
  • 需要自行维护服务器
  • 需备案（国内服务器）

二、常用插件及功能

2.1 评论系统

  • Disqus：国际主流评论系统，国内访问不稳定
  • Gitalk：基于 GitHub Issue 的评论系统，需 GitHub 账号
  • Giscus：基于 GitHub Discussions 的评论系统
  • Valine：基于 LeanCloud 的无后端评论系统
  • Waline：Valine 的衍生版本，支持更多功能
  • ** utterances**：基于 GitHub Issue 的轻量评论系统
  • 来必力（Livere）：韩国的评论系统，有中文版
  • 畅言：搜狐旗下评论系统，国内访问快，需备案

2.2 搜索功能

  • hexo-generator-search：生成搜索索引（XML/JSON）
  • hexo-generator-searchdb：生成搜索数据库
  • Algolia：第三方搜索服务，速度快
  • 本地搜索：配合主题内置的搜索功能

2.3 文章增强

  • hexo-abbrlink：生成文章唯一 ID（短链接）
  • hexo-generator-sitemap：生成站点地图
  • hexo-generator-feed：生成 RSS 订阅
  • hexo-asset-image：文章资源图片管理
  • hexo-wordcount：字数统计
  • hexo-reading-time：阅读时长估算
  • hexo-toc：生成目录
  • hexo-footnotes：脚注支持

2.4 代码高亮

  • hexo-prism-plugin：Prism.js 代码高亮
  • hexo-highlight：内置代码高亮
  • 主题自带高亮：多数主题自带高亮方案

2.5 数学公式

  • hexo-math：MathJax 支持
  • hexo-katex：KaTeX 支持（更快）
  • hexo-filter-mathjax：MathJax 过滤器

2.6 图片处理

  • hexo-lazyload-image：图片懒加载
  • hexo-image-sizes：自动生成响应式图片
  • hexo-filter-responsive-images：响应式图片

2.7 SEO 优化

  • hexo-generator-seo-friendly-sitemap：SEO 友好的站点地图
  • hexo-baidu-url-submit：百度主动推送
  • hexo-submit-urls-to-search-engine：主动推送到搜索引擎
  • hexo-seo-autopush：SEO 自动推送
  • hexo-generator-archive：归档页生成
  • hexo-generator-category：分类页生成
  • hexo-generator-tag：标签页生成

2.8 部署相关

  • hexo-deployer-git：Git 部署（GitHub/Gitee 等）
  • hexo-deployer-rsync：Rsync 部署
  • hexo-deployer-sftp：SFTP 部署
  • hexo-deployer-aliyun-oss：阿里云 OSS 部署
  • hexo-deployer-cos：腾讯云 COS 部署

2.9 安全与防护

  • hexo-nofollow：外链自动添加 nofollow
  • hexo-filter-nofollow：外链 nofollow 过滤器

2.10 其他实用插件

  • hexo-admin：后台管理界面
  • hexo-draft：草稿功能
  • hexo-migrator-wordpress：从 WordPress 迁移
  • hexo-migrator-rss：从 RSS 迁移
  • hexo-all-minifier：压缩 HTML/CSS/JS
  • hexo-browsersync：浏览器实时刷新
  • hexo-server：本地预览服务器

三、中国大陆地区相关操作

3.1 ICP 备案

  • 使用国内服务器/云服务必须备案
  • 使用国内 CDN 绑定自定义域名需备案
  • 阿里云 OSS / 腾讯云 COS 绑定自定义域名需备案
  • 备案需提供身份证、域名证书等材料
  • 备案周期通常为 7-20 个工作日
  • 个人备案与企业备案流程不同

3.2 GitHub Pages 加速方案

  • Cloudflare CDN：免费 CDN，全球加速
  • jsDelivr：免费 CDN，加速静态资源
  • 七牛云 / 又拍云：国内 CDN，需备案
  • Gitee Pages 镜像：国内镜像站点
  • Vercel / Netlify：海外平台但国内访问尚可
  • 静态资源 CDN 托管：图片、JS、CSS 放 CDN

3.3 国内访问优化

  • 使用国内 CDN 加速静态资源
  • 图片使用国内图床（七牛云、又拍云、SM.MS 国内版）
  • 减少海外资源依赖（Google Fonts、Gravatar 等）
  • 替换为国内镜像：
    • Google Fonts → 字体天下 / 百度静态资源
    • Gravatar → Cravatar / 七牛镜像
    • Disqus → 国内评论系统
  • 启用 Gzip / Brotli 压缩
  • 图片懒加载和 WebP 格式

3.4 合规要求

  • 网站备案号：备案后需在页脚展示备案号
  • 公安备案：部分地区要求公安备案
  • 隐私政策：收集用户信息需提供隐私政策
  • 版权声明：原创内容声明

3.5 域名相关

  • 国内域名注册：阿里云、腾讯云、华为云
  • 国外域名注册：Namecheap、GoDaddy、Cloudflare
  • 域名解析：国内推荐 DNSPod、阿里云解析；国外推荐 Cloudflare
  • 域名实名认证：国内域名必须实名认证

3.6 国内图床选择

  • 七牛云（免费额度 10GB/月）
  • 又拍云（需要申请联盟）
  • 腾讯云 COS（按量付费）
  • 阿里云 OSS（按量付费）
  • SM.MS（有免费版）
  • 自建图床（需要服务器）

3.7 搜索引擎优化（国内）

  • 百度搜索资源平台提交
  • 百度主动推送（实时推送）
  • 百度自动推送（JS 代码）
  • 360 搜索站长平台
  • 搜狗站长平台
  • 神马搜索站长平台
  • 生成百度网站地图（sitemap）
